# Contributing to Awesome AI Shopping Agents

Thank you for your interest in contributing!

## Guidelines

### Adding an Agent

1. The agent must be focused on autonomous shopping or purchasing tasks
2. Include: name, builder/company, type, key features, and open-source status
3. If open source, include a link to the GitHub repository
4. Keep descriptions factual and concise

### Adding a Platform Policy

1. Must be based on official platform announcements or reliable reporting
2. Include the date the policy was announced or took effect
3. Link to sources where possible

### Adding a Protocol/Standard

1. Must have a public GitHub repository
2. Include current star count (we will verify)
3. Describe the protocol's purpose in one sentence

### General Rules

- One item per pull request
- Follow the existing table format
- Keep descriptions under 100 words
- No promotional language
- Verify all links before submitting

## Process

1. Fork this repository
2. Create a branch: `git checkout -b add-agent-name`
3. Make your changes
4. Submit a pull request with a clear description

## Code of Conduct

Be respectful and constructive. We reserve the right to reject contributions that don't meet our quality standards.
